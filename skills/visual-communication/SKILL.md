# Visual Communication

Choose Mermaid for concise source-controlled diagrams, SVG/HTML/CSS for polished dark-mode visuals, tables for compact comparisons and prose when no visualization is needed. Never invent edges/nodes: ground in inspected repository or clearly label proposals. Provide source on request. Test with renderer if one is available; do not claim rendered output without evidence. Avoid large diagrams and unnecessary app edits. Do not introduce external renderers without approval.

Optional integration: if the independent `archify` skill is already installed and explicitly approved for the task, it may be used for high-fidelity standalone HTML/SVG diagrams. Never install or update it automatically, never redistribute its assets, and fall back to Mermaid or local HTML/CSS/SVG when it is unavailable.
